# تحديث تلقائي لمشروع Replit من كمبيوتر حقيقي (Playwright)

هذا الحل يحتاج كمبيوتر (ويندوز/لينكس/ماك) - مش هيشتغل على موبايل/بايدرويد.

## 1. التثبيت
```bash
pip install -r requirements.txt
playwright install chromium
```

## 2. جهّز ملف الكوكيز
حط ملف `cookies.txt` (اللي صدّرته من فايرفوكس بصيغة Netscape) في نفس
المجلد اللي فيه `keep_project_alive_desktop.py`.

## 3. التشغيل
```bash
python keep_project_alive_desktop.py
```

هيحصل الآتي:
1. هيفتح متصفح Chromium حقيقي (تقدر تشوفه على الشاشة).
2. هيحمّل الكوكيز بتاعتك ويدخل مباشرة على صفحة المشروع - وانت مسجل
   دخول تلقائيًا.
3. بما إنه متصفح حقيقي، تحدي Cloudflare هيتعدّى طبيعي (مش هيرجع 403
   زي ما كان بيحصل مع بايثون العادي على الموبايل).
4. هيفضل يعمل تحديث (reload) للصفحة كل 30 ثانية باستمرار.

## للإيقاف
اضغط `Ctrl+C` في التيرمينال، أو اقفل نافذة المتصفح.

## لو ظهرت رسالة "الجلسة منتهية"
معناها الكوكيز خلصت صلاحيتها. الحل:
1. افتح فايرفوكس، اتأكد إنك مسجل دخول في replit.com (أو سجل دخول تاني).
2. صدّر `cookies.txt` جديد بنفس الطريقة اللي عملتها قبل كده.
3. استبدل الملف القديم بالجديد وشغّل السكربت تاني.

## ملاحظة أمان
ملف `cookies.txt` بيدي دخول مباشر لحسابك - متشاركوش مع حد ومترفعوش
على أي مكان عام.

## تشغيل بدون إظهار المتصفح (اختياري)
لو حابب السكربت يشتغل في الخلفية بدون ما تشوف نافذة المتصفح، غيّر في
الكود:
```python
browser = p.chromium.launch(headless=False)
```
إلى:
```python
browser = p.chromium.launch(headless=True)
```
(جرّبه الأول بـ headless=False للتأكد إنه شغال تمام، وبعدين غيّرها).
